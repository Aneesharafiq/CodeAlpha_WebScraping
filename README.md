# CodeAlpha Web Scraping Project

## Project Overview

This project was completed as part of my CodeAlpha Web Scraping Internship.

The purpose of this project is to collect book information from the practice website **Books to Scrape** using Python and BeautifulSoup.

## Data Collected

The following information was scraped:

* Book Title
* Price
* Rating
* Availability

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas
* Google Colab

## Methodology

1. Sent HTTP requests to the website.
2. Parsed the HTML using BeautifulSoup.
3. Identified book elements from the webpage.
4. Extracted title, price, rating, and availability.
5. Stored the collected data in a Pandas DataFrame.
6. Exported the final dataset as a CSV file.

## Output

The final dataset is available in `books_dataset.csv`.

## Learning Outcome

Through this project, I learned how to:

* Send requests to a website using Python.
* Parse HTML pages.
* Extract structured information from webpages.
* Create a custom dataset using web scraping.
* Save scraped data as a CSV file.
