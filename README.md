# CodeAlpha Data Analytics Internship Projects

Welcome to my GitHub repository for the CodeAlpha Data Analytics Internship. This repository contains three completed projects demonstrating web scraping, exploratory data analysis, and data visualization.

## Task 1: Web Scraping
- Scraped book information from Books to Scrape using Python, Requests, and BeautifulSoup.
- Collected book titles, prices, ratings, and availability.
- Cleaned the price data and exported the dataset to CSV format.

## Task 2: Exploratory Data Analysis (EDA)
- Analyzed the books dataset using Python and Pandas.
- Explored price distribution, ratings, missing values, and potential outliers.
- Used data analysis techniques to identify patterns and summarize findings.

## Task 3: Data Visualization
- Created a dashboard using Microsoft Power BI.
- Presented key information about book prices, ratings, and availability.
- Designed visualizations to make the dataset easier to understand.

## Tools and Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- Google Colab
- Microsoft Power BI

## Dataset
The project uses book data collected from Books to Scrape for educational purposes.
